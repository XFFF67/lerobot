等待 XR 状态…
  • 连接后先松开两侧握把，再按住对应握把，移动或旋转手柄控制手臂。
  • 握把按住时：扳机张开夹爪，松开扳机闭合；松开握把保持当前状态。
  • 右握把 + 右摇杆上下：沿当前轮向行驶；右摇杆左右不控制转轮。
  • 右握把按住、左握把松开 + 左摇杆左右：调整轮向。
  • 左握把按住 + 左摇杆上下：升降，此时左摇杆不控制轮向。
  • 右握把 + B / Y：顺时针 / 逆时针自转。按住按键等待轮组切换完成。
  • 右握把 + 右摇杆按下：切回平移并回正轮组。握把松开时 X / A 复位对应手臂。

在电脑 MuJoCo 窗口观察机器人。此页面不传输仿真相机画面；透视模式可用于看电脑屏幕（取决于头显支持）。

面向电脑，松开握把、摇杆回中后长按右手柄 Meta 按钮约 3 秒重新居中，再开始控制。
