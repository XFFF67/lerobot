手柄操作与退出

握住左 / 右侧面握把：对应手臂跟随移动和旋转。松开即保持，可以换位置重新握住。

握住时按扳机张开夹爪，松开扳机闭合。握把松开时，X / A 让对应手臂回位。

右握把按住、左握把松开：左摇杆左右转轮，右摇杆上下行驶，可同时操作。

左握把按住 + 左摇杆上下：升降，此时左摇杆不转轮。

右握把 + B / Y：顺时针 / 逆时针自转；等待轮组切换完成。按下右摇杆切回平移并回正。

面向电脑，松开握把、摇杆回中，再重新居中。打开头显系统菜单会暂停控制；会话仍在运行时，同一个按钮显示“退出控制”。

机器人画面显示在电脑 MuJoCo 窗口；透视模式可用于观察电脑屏幕。

电脑真机程序启动后先缓慢抬肘，到位后才接受握持控制。连接网页不代表机械臂已经准备好。

握住时按扳机张开夹爪，松开扳机闭合。松开两侧握把，按左手 X：双臂缓慢复位到 J4 90°、其余关节 0°，夹爪保持。复位中握住任一握把可中止；完成后松开再握恢复跟随。

左 Grip + 左摇杆上下控制升降。右 Grip + 右摇杆上下行驶；左 Grip 松开时，左摇杆左右在 -90°～90° 内调整轮向。按下右摇杆切换平移／自转，自转时用右摇杆左右旋转。松开右 Grip 只停车，保持轮向和当前构型，不自动回正。

松开握把、丢失追踪或退出 VR：机械臂保持上力。要缓慢放下，在电脑真机控制终端按 Ctrl+C；到位后程序自动失能。

重新居中前松开握把；恢复后先松开再握住。通过透视观察实物，电脑窗口（若启用）显示实测关节姿态。
